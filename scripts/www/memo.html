CloudBase 配置
填写环境 ID 和 Publishable Key 后即可开启云端同步
首次使用请完成以下配置
  1. 在 CloudBase 控制台创建个人版环境（免费）
  2. 「身份认证 → 登录方式」开启 匿名登录
  3. 「环境配置 → API Key 配置」生成 Publishable Key
  4. 「数据库」新建集合 mc_memo_v1
  5. 集合权限设为 {"read": true, "write": true}
  6. 将环境 ID 与 Publishable Key 填入上方，保存即可
